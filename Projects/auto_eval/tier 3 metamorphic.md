## A. What makes this tier different

Every other tier reads a *correlate* of one forward pass and infers what drove the output. Tier 3 constructs the counterfactual: change one thing, hold the rest byte-identical, observe whether the output moves as the spec requires. It is the only reference-free evidence in this design that is causal, and it is why an MR can falsify a claim the model makes about itself ([Turpin et al., NeurIPS 2023](https://arxiv.org/abs/2305.04388)). What it concludes: "this axis does / does not depend on input feature X, with effect size and a CI." What it cannot: that any level is correct. Three bounds:

1. Input-intervention tests establish **self-consistency**, "a necessary, but not sufficient test for faithfulness", and they disagree by up to 64 points on the same model/task ([Parcalabescu & Frank](https://arxiv.org/html/2311.07466v4)).
2. MT is structurally blind to **consistent hallucinations** ([Zheng et al.](https://arxiv.org/html/2605.13898v1)). A systematically over-coded RISK rung — the compliance exposure the product exists to prevent — passes every MR here.
3. **On this corpus the apparatus is measuring a two-stage pipeline whose first stage is itself an LLM, and that stage dominates.** ✅ The formatted note reproduces byte-identically across `run1`/`run2-confirm` in **23/402 (5.7%)** encounters (median |Δlen| 29 chars). On exactly those 23, the `ed-pro-scoring` output is byte-identical **23/23** and no axis moves — because an identical note is an identical request is a cache hit. So the measured 5–9% "null" is **not decomposable** from these two runs, and the frozen-note null this tier actually runs against is **UNMEASURED**. *Measurement that settles it: NULL-1 below, 800 calls.*

Tier 3 buys high precision and near-zero recall on the failure mode that matters. It is a ranking-and-defect-class instrument, never an accuracy claim.

Nothing in steps 4+ runs until step 3 passes.

**3 · Validate the apparatus — NULL-1, and it is not free.** Two *distinct fresh* seed lanes, byte-identical frozen note in both arms, n=100. θ̄ must land near 0 with CIs containing 0; assert `cache_hit == false` on every draw. **Stop the build if it doesn't.** The draft's free control (pseudo-arms split out of the existing 4-draw sets) is cached-vs-cached from one era and cannot see the apparatus's dominant artifact — arm A replaying while arm B pays. Also pin a **dated model snapshot**, not the `claude-sonnet-4-6` alias: the model *string* is in `run_signature`, so an alias rotation does not invalidate the cache and would appear as a violation on every MR simultaneously.

**4 · Preconditions + spec (free).** Per MR, filter to its non-vacuous stratum from § B.3. Spec = JSONL, one record per (encounter × MR × variant), carrying `mr_id`, `mr_version`, `layer`, `ops`, `expect{axis, type, tolerance, precondition_snapshot}`, `domain_validity{}`, `synthetic: true`. **Void the run unless:** the perturbed note is non-empty (`ed_coding_v1_activities.py` falls back to the *original* note when it is falsy, and the run still looks successful); **both** `rcm-format-notes` (`f0e1d2c3`) and `rcm-split-notes` (`d7a3f1e2`) are overridden (split-notes alone still runs the formatter → 5 calls, not 4); the override node resolves to `tool_name == "rcm-split-notes"`; `note_segments` is recomputed or explicitly dropped; **no channel-deletion MR runs against a nullish channel**; and the removed content is absent from **every other channel** before any `upstream-input` disposition is allowed.

**5 · Domain-validity gate (deterministic, pre-execution).** Criterion-relevant entities / numbers / units / negations preserved; `core.dataset.check_note_content` passes; length above tier 0's 5th-percentile; headers intact. **Named protected entities** the draft's "numbers preserved" does not cover: **age tokens** (age gates all four axes — `copa_prompt.py` opioid-at-discharge ≥18, pediatric MSK <18 with an explicit adult non-qualifier, febrile child 0–5; `data_prompt.py` pre-verbal <3 credits the historian *automatically*, true in 94/402 ✅; `facility_prompt.py` age 0–6 months; `risk_prompt.py` childbearing age), provider names + specialties, disposition words, dates/timestamps, negation cues, drug names + routes. Emit **two-dimensional verdicts** (relation × domain); only low-domain/high-relation is a defect; high-domain rows are `out-of-relation-domain` in a suppressed denominator.

**6 · Run the arms — the note is frozen in BOTH.** This is the load-bearing correction. A control arm run as a plain `core.harness --seed k` redraws the formatter, so the arms differ by your edit **plus** a note redraw that lands in **94.3%** of encounters ✅. K_orig == K_pert, enforced in the loader. Both arms pay in full. Wide pass K = 3; narrow K = 6 only inside cells surviving multiplicity level 2. K = 1 makes the estimator undefined; K = 3 cannot produce a per-encounter verdict; K = 4 is strictly worse than K = 3 at q < 1. Clinic's K = 6/K = 9 is **not** free-by-assumption but it *is* free-in-fact at n = 63: `clinic/experiments/20260720-feedback-iter-2-rca/results/repro-seed{1,2,3}` each carry a per-vote `nodes/` trace = **R=3 × 3 votes = 9 per-vote draws already paid for** (⚠, and § G's "no same-input clinic run pair exists" was false). Block-permute clinic **by run**: three concurrently-issued within-run votes are not exchangeable with votes from another run. One `--out-dir` per (MR, lane); `pgrep -f core.harness` first (concurrent runs stall, cache flushes only at completion).

**7 · Statistic, with its units stated.**

```
θ̂ = mean over the K² cross-arm pairs 1(L ≠ L′)
      − ½·[ mean within-A disagreement over the K(K−1) ORDERED DISTINCT pairs
          + mean within-B disagreement over the same ]
E[θ̂] = ½‖π − π′‖²₂
```

Two corrections. (i) **The within-arm term is over K(K−1) ordered distinct pairs, not K².** Including i = i (disagreement 0) understates within-arm noise by (K−1)/K = **2/3 at K = 3** and makes θ̂ positively biased — the estimator itself manufactures violations. (ii) **θ̄ is not a violation rate.** It is half a squared L2 distance: a deterministic one-rung flip gives θ_e = 1; turning a point mass into a fair coin between two rungs gives θ_e = 0.25. θ̄ = 0.025 is "2.5% flipped outright" *or* "10% destabilized" — a 4× ambiguity, and destabilization is the *expected* shape given ⚠ ~15% of encounters already sit on a rung boundary. So publish θ̄ **and** the affected-encounter fraction, and quote every MDE with its q (`statistical-design.json`'s 0.90%/1.63% are simulated at **q = 1.0**, where the two coincide; at the achievable n they are ~1.2% on test215 and unattainable on wa402 as configured).

**8 · Test — pick one, and say which.** Independent lanes ⇒ the 2K draws are exchangeable under H₀ ⇒ exact conditional permutation over C(2K,K), min two-sided p = 0.10 at K=3 / 0.0022 at K=6. Same-lane coupling (which is what makes the cheap call counts possible, because unperturbed nodes hit what the first arm wrote) ⇒ draws are **clustered by lane** and the unrestricted permutation is **invalid**; the valid test is the within-lane sign flip over 2^K arrangements, min two-sided p = **0.25 at K=3**, 0.031 at K=6. The draft assumed the cheap cost and the expensive test's resolution. **Decision: independent lanes for every v1 MR** — an order of magnitude of resolution is worth 2× the calls, and § C-3's guard (`cache_hit == false`) requires it anyway. Arm-label swaps apply to an entire encounter's block, jointly across axes. Two-sided on θ̂ for INV; one-sided on Δ̂ for directional.

**9 · Primary endpoint, per MR class.** **Δ̄ (signed rung shift) is primary for every directional and rule-derived MR** — for those, a *large* θ̄ means the MR **passed**, and the draft's blanket "population MR-violation rate as θ̄" inverted the reading for most of the catalogue. θ̄ is primary only for INV-1 and NULL-1. Either way: per **(MR, axis)** on the screened stratum, 95% percentile bootstrap CI **resampling encounters** — one index vector driving both arms, all axes, all MRs. Report coverage every time: the excluded U stratum carries ⚠ **5.8–6.0× the billed-code error rate** of S, routed to tier 2. Never pool datasets.

**10 · Multiplicity.** Level 1: per MR pooled across axes, BH q = 0.05. Level 2: per (MR, axis), BH q = 0.10 — **the reportable unit**. Level 3: per encounter, localization only, no correction, feeding tier 6's conformal queue. `causes.json` promotion requires K ≥ 6 **and** a corroborating tier-1 or tier-2 signal.

### (i) The deterministic DATA recompute

The recompute never disagrees (declared == recomputed 402/402 on run1 ✅, 709/709 across three datasets), so it absorbs change by **quantization**, not by overriding: `min(n,3)` per bucket, `min(Σ,6)` on Category A, then the 3/6/12 thresholds. Measured attenuation: counts 15.42% → points 10.45% → level 7.46%. Ruling, unchanged: **DATA is scored at L0 (counts) primary and L2 (points) as the rule-entailed expectation; the declared level is a tier-1 side-check** (it survives in the output dict as `data_level_llm` but drives nothing ✅). RULE-1-EKG and RULE-2 exist precisely because they place their predicted effect *relative to the quantizer* — a 2-point step against a cap, a 6-point step against the 12-point threshold. One added caveat: **RULE-1's unit must be the unique test *type*, not the order line** — `data_prompt.py:19-27` collapses "CT HEAD + CT CHEST + CT 2D RECONSTRUCTION = 2 unique test types", and `business_logic.py` prefers `len(data_tests_ordered)` over the integer count, so removing one *line* can be a 0-point edit even inside the must-move stratum.

### (ii) The two-of-three median, and clinic's second mask

`calculate_mdm_level` returns the second order statistic ✅ — a measured low-pass filter: 58.5% of axis-moving pairs leave the billed code identical. With axes sorted x ≤ y ≤ z, MDM_new = max(x, y − d), so a downward pivot move is absorbed exactly when x == y (45.0% of wa402). Three consequences. (1) L3/L4 is never primary. (2) **RULE-3 is demoted from an MR to a conditional readout**: "target axis at the minimum → MDM must not move" is **not entailed**, because `ed-pro-scoring` emits COPA, DATA and RISK from **one** call and **one** user turn — there is no note-layer single-axis perturbation, and any co-movement of a second axis moves the median legitimately. The only injection point that decouples pass 1 from pass 2 is the consumer-module monkeypatch this design rejects. So RULE-3's null arm must **condition on the observed post-perturbation levels of the other two axes**, and it rides on another MR rather than standing alone. Note also that removing the orders has a rule-entailed *downward* direction on COPA too (`copa_prompt.py:38-47`: COPA=High's mandatory pathway requires the confirmatory workup to be **ordered or completed**), so RULE-3 cannot be composed with RULE-1/DIR-DN-1 at all. (3) Directional MRs at L3/L4 need explicit floor/ceiling exclusions: ⚠ 85/402 sit at the High ceiling, and `_PRO_MDM_TO_CODE` has **no 99281**, so a downward move saturates at 99282.

## D. Confounds, ranked by likelihood of producing a false finding

**D-1 · The frozen-note null is unmeasured, and every imported constant belongs to a different apparatus.** ✅ The published nulls (COPA 8.96 / DATA 7.46 / RISK 5.22 / PRO 8.46% on wa402; π_U ≈ 0.15; the S/U strata; MDE 0.90%/1.63%; PPV 18.5%; the 5.8–6.0× stratum-U enrichment) were all measured on **full-DAG lanes where the note redrew in 94.3% of encounters**. This tier is a frozen-note apparatus. θ̂'s unbiasedness survives; **none of those constants do.** Guard: NULL-1 re-measures the null under the freeze before any MR is interpreted, and every imported constant is labelled apparatus-specific in the manifest. The arithmetic that motivates θ̂ is unchanged and still exact: under H₀ the two draws are i.i.d., so P(reject) = 1 − Σπ² and **the naive test's size is the pipeline's instability, with the perturbation never entering**. And the noise is a two-component mixture (~85% point masses, ~15% adjacent-rung coins), so the false positives are produced almost entirely by the boundary encounters where a real effect is most likely — a confounded subpopulation, not additive noise. You cannot subtract a global p. **"Any move is a defect, full stop" is deleted.**

**D-2 · Cache-replay degeneracy — new, and top-ranked with D-1.** ✅ A frozen-note arm run inside an already-materialized lane is a **replay**, not a draw: within-arm disagreement = 0, and

```
E[θ̂] = (1 − Σπ²) − ½(1 − Σπ²) = +½·p   ≈ +4.5 / +3.7 / +2.6 pp on COPA / DATA / RISK
```

The apparatus would report violations everywhere, and the draft's own cache section points straight at the trap ("the original arm replays free"). Evidence it is real, not hypothetical: on the 23 encounters where the note reproduced, the pro-scoring output was byte-identical **23/23** with **0** axis moves ✅. Guard: identity and control arms use K *distinct* fresh lanes; assert `cache_hit == false` per call for every perturbed **and** control node.

**D-3 · The note formatter rewrites the perturbation away.** `rcm-format-notes` is a real `claude-sonnet-4-6` call (+161 lines median; the raw note is a substring of the output in 1/402). Any MR injected upstream measures the formatter's idempotence and a null is indistinguishable from a pass. Guard: inject **post-format** at `rcm-split-notes` *and* override `rcm-format-notes`, which also bypasses the fresh formatter draw whose `correction` format can cosmetically repair a deletion seam. **Clinic is exempt** — its format-notes node is a no-op on all 6 datasets, so a clinic note edit is byte-exact.

**D-4 · The citation resolver is lossy, and "verified 1339/1339" verifies it against itself.** ✅ `packages/rcm/common/rcm_citations/__init__.py` states it outright: "LLMs are unreliable at character counting, so offsets are recomputed in Python with a three-tier fuzzy `str.find` (exact → first-80 → normalised first-25)"; tier 2 **overwrites** `cited_text` with the 80-char prefix; "a quote that can't be located is **dropped** (no chip) rather than returned at a wrong position." So `note[start:end] == cited_text` holds **by construction**. Measured fates of the model's 6,059 own spans ⚠ (Critique 1, consistent with my ✅ counts of 6,059 raw / 4,750 `guideline_report` citation objects / 0 offsets on the raw set): kept whole 2,843 (46.9%) · truncated to 80 chars 203 (3.4%) · normalised sub-span 890 (14.7%) · **dropped entirely 2,123 (35.0%)**, with ≥1 drop in 398/402 encounters. Four consequences: COMP-1 addresses at most ~65% of the model's spans and 18% of those only as a prefix (redacting a prefix leaves the rest of the quote in the note, so "level held" is the *correct* outcome and would be written up as SUSPECT); the 35% dropped are the stitched/paraphrased/absent spans — **the ones most likely to be post-rationalized**, so COMP-1 is systematically blind to the failure mode it exists to detect; **"zero model calls and no fuzzy matching" is false** — the fuzzy matching already happened, lossily, upstream; and § B.3's span-level strata are computed on the raw pool while the executable population is the resolved pool. Guard: run **our own matcher over the raw `llm_raw` strings**, record the resolving tier per span, exclude tier-2/tier-3 spans from COMP-1 or redact the full matched extent, and state COMP-1's denominator as the tier-1-exact subset with its coverage.

**D-5 · A span/element serving more than one axis.** ⚠ 327 of 5,716 distinct spans (5.7%) are cited by >1 axis but **204/402 encounters (50.7%)** contain at least one. The unit is the **element** (§ B.1 COMP-1), shared spans excluded or given a two-axis expected effect. An encounter-level deletion test inherits a ~50% confound rate.

**D-6 · Redundancy makes "must drop" the wrong expectation on the modal encounter.** COPA, RISK and the facility checklist are **max** rules, stated as such in the prompts ("highest matching level wins", "HIGH — ANY of", "Apply the HIGHEST level supported"). Under a max rule, removing one element lowers the rung **iff** it was the unique element at that tier. ⚠ ≥2 same-tier elements: RISK=High 11/63, RISK=Moderate 80/249, COPA-High 23/89, facility 139/402; and the axis rests on a *single* cited span in only **37 of 1,206 axis-encounter cells (3.1%)**. So REDUNDANT is the modal outcome, not a refinement. Guard: element-level unit + the exactly-one-element stratum; the ≥2-element stratum is **excluded**, not counted as REDUNDANT. Separately, ⚠ **90/402 (22.4%)** encounters have a RISK rung with *no* structured boolean at all (Low and Minimal have none), and ⚠ 39/402 declare a facility level with zero criteria at that level, 22/402 a RISK tier with zero same-tier booleans, 32/89 COPA=High with neither High flag — **an MR whose readout is "the supporting element must drop" cannot run on a row whose declared level has no supporting element.** Those are tier-1 findings.

**D-7 · Universal LLM order/distractor sensitivity — ours or everyone's?** Large and quantified: up to 76 accuracy points of formatting spread ([FormatSpread](https://arxiv.org/abs/2310.11324)), >30% drops from premise permutation, a U-shaped position curve, irrelevant sentences degrading reasoning ([GSM-IC](https://arxiv.org/abs/2302.00093)). INV-1 **will** fire at a nonzero encounter-independent base rate. Verdict, not a hedge: the process this product replaces is invariant to formatting and patient identity, and [Gourabathina et al. (FAccT 2025)](https://dl.acm.org/doi/10.1145/3715275.3732121) measured exactly this *with a human control*. **Universality changes the disposition — population-level prompt fix, frozen gating suite — not the verdict.** Operationally: per-model per-MR baseline on a random sample first; encounter-level findings are excess over it; report the population number as a spread.

**D-8 · Generated vs templated perturbation.** Templated first. A paraphrase that drops a negation, rounds a lab value, or converts "no acute distress" to "stable" legitimately changes the correct level, and there is no GT to catch it; in Cho et al.'s 937-violation audit, input-transformation error was the largest FP category. INV-2's second noise term is **UNMEASURED** (*measurement: cross-family paraphraser + deterministic preservation check + coder audit of 50 paraphrases, reporting the share that alters a criterion-relevant fact*). Until then n = 100–150, never pooled, own bucket in `calibration.json`.

**D-9 · Silent coercion — 18 booleans wide, and the guard is path-dependent.** `_coerce_bool` (`data_model.py:38`) maps `None`/`""`/`"null"`/unrecognized → **False** for all 18 criterion booleans ✅, and L0 is the primary observable for every INV MR — so a perturbation that degrades JSON quality manufactures a full L0 down-move on all three axes. That is a much larger surface than the level coercion. `_coerce_level` (`:99`) maps unrecognized → the bottom rung, but **for COPA only** in practice: DATA's declared level is discarded by the tail, and RISK raises and triggers an instructor retry. The guard "assert the pre-coercion level string was in `_VALID_LEVELS`" is available only on the **thinking path** (`ed_coding_v1_activities.py:374-382`, which records raw `json_text` — and is the path wa402's pro node uses); the **instructor path** (`:396-411`) records `result.model_dump_json()`, i.e. post-coercion, where an omitted field is indistinguishable from a model-asserted `False`. Assert which path produced each record (`params.thinking_budget` present) before relying on it. Related framing fix: **fac, data and risk all run at T=0 — ED has exactly one stochastic node**, so D-1's "temperature=1 pipeline" misplaces the noise.

**D-10 · The perturbation silently not landing.** Covered in § C-4; listed here because it produces a *passing* invariance test on the unperturbed input. `core.dataset validate` would catch an emptied note but refuses aggressive-deletion variants outright, so tier 3 goes through `core.harness` directly and loses that guard — hence the sentinel.

**D-11 · Strata defined on a single baseline run that the perturbation re-draws.** Counts move 15.42% on identical input, so ~15% of RULE-1 stratum assignments are invalid, concentrated at the n=3/4 cap boundary that *defines* the stratum. Same for RULE-2 (exactly one 6-pointer), RULE-3 (pivot position), CLONE-1 (gates). `precondition_snapshot` records the problem; it does not fix it. Guard: define every precondition on the K₀ frozen-note screening lanes with unanimity required on the stratifying statistic, re-verify membership in the perturbed arm, and report a **two-way stratum table** rather than assuming membership held.

**D-12 · Reading the abstention-masked fields** — see § C-0.

**D-13 · Prod/harness divergence on the pass-2 metadata block.** ✅ `pat_age` and `attending_prov_name` are absent as *columns*, but `arrival_age` (89 distinct values) is present and `first_atnd_prov_name` is present-but-literal-`"null"` in 402/402. ⚠ Prod aliases `arrival_age → pat_age` and `first_atnd_prov_name → attending_prov_name` (`dispatch.py:109-112`); the harness does not. So the cached pass-2 block carries 7 of prod's 9 keys, and **an invariance pass on the harness does not certify prod** — prod sends one prompt-visible field (age) that is emphatically *not* an invariance. Record this as a standing harness-fidelity finding; it is also why the age token is a protected entity in § C-5.

**D-14 · The `upstream-input` disposition is the most dangerous cell in the design.** ✅⚠ Its premise ("the channel never reached the model") is false in the majority of cases — 73.3% of listed tests are also in the note, and the MAR channel does not exist at all — and a finding there exits the prompt-fix lane and cannot be falsified by any later tier. Precondition, hard: a deterministic check that the removed content is absent from **every other channel** (tier 0's job, free).

## G. V1 cut line, and honest limits

### The cut line

**V1 — build now.** Cheap, low confound, no qh-platform change, and every item is interpretable without a constant this tier does not yet own.

| step | what | calls | gate |
|---|---|---|---|
| **0** | Precondition scan + strata over existing run dirs; readout fixes (case-fold, `llm_raw` string parse, CC fields, offset assertions); the three tier-1 handoffs in § F; our own span matcher with resolving tier recorded | **0** | kills vacuous MRs before any spend, and ships three findings on day one |
| **1** | Plumbing: per-encounter override index + `--freeze-note` / `--perturb` + manifest field + spec-sha guard | **0** | ~25 lines, `core/` only |
| **2** | θ̂ (K(K−1) within-arm term), exact permutation, `mean_ci` beside `_resamples`, `mr_selftest.py` | **0** | **stop if the selftest fails** |
| **3** | **NULL-1** — frozen-note identity, two distinct fresh lanes, n=100 | **~2,400** | **stop if θ̄ ≠ 0.** This is also the biggest available product finding (see below) |
| **4** | **RULE-1-EKG** (+ RULE-3 as a conditional readout, free, same perturbation) | ~2,400 at n=100 | expectation is a theorem about `business_logic.py`'s caps *and* a prompt clause that forbids the note channel; ships with a spec-predicted null arm that is the **same** perturbation |
| **5** | **ATTRIB-1**, n=208 | ~5,000 | rule-entailed by `data_prompt.py`, SAFE, single-boolean L0 readout, redacts a marker not a clinical fact, and it is the MR a payer auditor would recognize first |
| **5b** | **INV-1**, n≈342 screened — **conditional**: runs in v1 only if NULL-1's frozen-note null lands materially below the 5–9% full-DAG figure; otherwise v2 | ~8,200 | its interpretability is entirely a function of the null it is compared against |

**V2 — needs a guard, a measurement, or a coder.** COMP-1 (needs the element-level stratum, the resolved-span matcher's coverage statement, COMP-1c, and coder sign-off) · RULE-2 (needs the element→span entailment step budgeted) · SECTION-1 (needs the section-gated clause inventory) · CLONE-1 (needs coder sign-off on "no substantive finding") · ANTON-1 restricted to management statements · clinic RULE-5 at interior bands + the free clinic null from `repro-seed{1,2,3}` · MFT-1 · the pass-1→pass-2 CoT-corruption tests · INV-2 / INV-5 at reduced n with the fidelity audit.

**V3 — needs a prod change or is near-unexercisable.** CC-2 on the 3 real encounters at K=6 · the CC minute ladder via MFTs · SUFF-1 as a labelled probe · DIR-DN-1 as a channel-provenance test · the DOS re-dating MR (`adt_arrival_time` is date-only, so the "outside this encounter" bucket reassignment needs a dataset with real timestamps) · any monkeypatch-based single-axis isolation.

**Why the line falls there.** V1 contains exactly one *un*-measured dependency (the frozen-note null) and it is v1's step 3, so the tier pays for its own calibration constant before it spends anything on a hypothesis. Every v1 MR reads out at L0 or L2 on a **single** boolean or a **single** point step whose expected magnitude is entailed by a prompt clause or a `business_logic.py` theorem — no max-rule redundancy, no OOD deletion, no clinical fabrication, no coder adjudication, no `guideline_report` span resolution. Everything that needs the resolver's coverage statement, an element-level clinical stratum, or a coder's ≥80% consensus is v2 by construction, because those are the three things that cannot be produced in a build cycle. And the v1 total (~10k calls, ~12–20 h serialized at 6–13 enc/min) is one MR-week, not the ~38,400 draws / 50–105 h the full draft catalogue implied.

**The finding v1 most likely produces is not an MR violation.** ✅ If NULL-1's frozen-note null lands materially below the 5–9% full-DAG figure, then the dominant source of ED run-to-run instability — and therefore of the ~6× billed-code error enrichment in stratum U — is **`rcm-format-notes`, a node nobody is looking at**, and the fix is caching or freezing it rather than prompt work on the scorer. The evidence pointing that way is already on disk: 23/402 identical formatted notes, and 0 axis moves on all 23. That reframes `features/ed-format-notes-cache/` from an eval-isolation convenience into a candidate product fix.

### Honest limits

- **Stable errors are invisible.** A systematically over-coded RISK rung, stable across order, paraphrase and demographics because it comes from a stable prompt misreading, passes every MR in the catalogue. Publish tier-3 **recall** against the labelled slice, expect it to be low, and keep the pairing: tier 3 finds instability, tier 4's blinded cross-family extraction finds stable-but-wrong, only human labels + PPI produce an accuracy number.
- **This measures self-consistency, not faithfulness.** The tests disagree by up to 64 points on the same model and task, and two ground-truth meta-evaluations find no faithfulness metric reliably ranks faithful above unfaithful. Any number ships as a calibrated detector with a PR curve, never as a headline rate.
- **θ̄ is not a rate**, and half the catalogue reads it backwards if you forget that. Publish θ̄, the affected-encounter fraction, and Δ̄ separately, and every MDE with its q.
- **The highest-error subpopulation is excluded by construction.** Stratum U is unidentifiable at any affordable K and carries ⚠ 5.8–6.0× the billed-code error rate. State it every time.
- **Nothing here sees an error whose signal was never in the note.** Input adequacy is tier 0's. Keep the naming collision pinned: ERASER-**rationale** sufficiency (tier 3) ≠ **input** sufficiency ([Joren et al.](https://arxiv.org/abs/2411.06037), tier 0).
- **Three named UNMEASURED quantities blocking specific MRs.** (a) The **frozen-note null** — NULL-1, 800–2,400 calls. (b) **INV-2's paraphrase-infidelity rate** — cross-family paraphraser + preservation check + coder audit of 50. (c) Whether **L0 movement with L1 held** carries an elevated GT error rate — checkable only on ✅ **71 labelled MDM rows per axis** on wa402, with a target subset in the teens; state that MDE or drop the gate. Clinic's null is **no longer** on this list: ⚠ `repro-seed{1,2,3}` give K=9 per-vote draws on 63 encounters, already paid for.
- **Two bookkeeping defects in the evidence base itself.** ✅ `washington-402-baseline/results/{run1,run2-confirm,run3-*}` carry **no `manifest.json`**, so the qh-platform revision behind § B.3's entire strata table and behind the measured 5–9% null is unrecorded — exactly the defect `CLAUDE.md`'s manifest rule exists to prevent, applied to the numbers this design rests on. And the model string in `run_signature` is the **alias** `claude-sonnet-4-6`, so a provider-side snapshot rotation is indistinguishable from a universal MR violation. Pin a dated snapshot and re-run the strata scan under a manifested run before any v1 finding is published.
